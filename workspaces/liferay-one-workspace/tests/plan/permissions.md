# Permissions

Every permission checker in liferay-one-etc-spring-boot. The REST endpoints call these classes to decide 403 versus allow, so each one is `planned`, and a JUnit + Mockito unit test proves both the allow and the deny branches.

> Autoscaffolded from the code surface (7 items). Edit the Requirement, Type, Priority, and Status columns freely. `scaffoldPlan` preserves them on rerun. Do not edit the ID column. When the code anchor of a row changes, edit its Source column so that the row keeps its ID.

| PERM-ACCOUNTPERMISSION | Account level access check — allow for Administrator and Liferay Staff roles, for account manager roles on ASSIGN_MEMBERS, for support account roles on VIEW, and for support ticket roles on UPDATE only within the matching account; ASSIGN_MEMBERS otherwise denies, other actions allow through a shared organization with the account, and a miss throws PrincipalException from check | unit | P0 | planned | permission:AccountPermission |
| PERM-ADMINPERMISSION | Global admin gate — allow only for Administrator or Provisioning Administrator roles, deny for any other or empty role list, and check throws PrincipalException on deny | unit | P0 | planned | permission:AdminPermission |
