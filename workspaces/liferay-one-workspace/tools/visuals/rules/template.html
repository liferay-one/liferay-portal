Rules

The workspace rules that a scan of the code can check, and each place that matches one. A match is a place to read, not a proven defect: the scan cannot see why a loop is small or why a field is safe. Open a rule to see its matches.

Generated by tools/visuals/rules from liferay-one-custom-element/src and the liferay-one-etc-spring-boot source, without tests. Each check names the rule file in .agents/rules that it comes from. A loop that walks the pages of one query is not reported. Each rule with matches is an action in workspace health.
