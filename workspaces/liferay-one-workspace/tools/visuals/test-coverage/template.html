Test Coverage

How much of the test plan has a real test, and which requirements those tests verify. A plan item is real when a test that is not a stub covers it, pending when only a failing stub covers it, and uncovered when no test does. Deferred items are out of go-live scope. The numbers match yarn plan:report.

By Tier

Plan items per test runner, at one scale. Deferred items sit at the end of each bar.

Generated from tests/plan/*.md, specs/business, specs/technical, and the test tags indexed by tests/scripts/lib. Epics come from the E numbers in a plan item's requirement text, so most unit rows have no epic. A test file marked * was matched by naming convention, not by a plan ID tag.
