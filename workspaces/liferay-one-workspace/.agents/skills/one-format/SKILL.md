# Format Source

Run all three steps from the workspace root (`workspaces/liferay-one-workspace`). Report errors and stop — do not continue to the next step if one fails.

## 1. Gradle source formatter

Formats Java, YAML, and other non-frontend files:

```bash
./gradlew formatSource
```

## 2. ESLint (auto-fix)

```bash
yarn lint:fix
```

## 3. Prettier (auto-format)

```bash
yarn format
```

## Manual rules

After the automated tools run, apply the manual rules from `.claude/rules/code-style.md`. Re-run steps 2–3 after any manual edits to catch formatter-driven cleanup.

Skip generated files (files tagged `@generated`, `$ANTLR`, `# This is a generated file.`, or `## Autogenerated`).
