# Business Requirements

This directory records what the Liferay One system must do for the business, one file per feature area. The row schema, the checks, and the steps to add an area are in [`../README.md`](../README.md).

| File | Area Code | Covers |
| --- | --- | --- |
| `identity-and-access.md` | `ACCESS` | Sign in, OAuth2 authorization, Okta sync, roles and the permission matrix, restricted pages, and guest access |
| `accounts-and-organizations.md` | `ACCOUNTS` | Accounts, organizations, users, invitations, the account selector, addresses, and contacts |
| `projects.md` | `PROJECTS` | Projects, project membership, project tabs, and contract filters |
| `marketplace-catalog.md` | `CATALOG` | The catalog, taxonomy, product detail, and listing visibility |
| `purchasing-and-orders.md` | `ORDERS` | Checkout, orders, payment methods, tax, license agreements, and the link from an order to a project |
| `entitlements.md` | `ENTITLEMENTS` | Entitlement creation from order items, entitlement definitions, and entitlement updates |
| `licensing-and-activation.md` | `LICENSING` | License keys, activation keys, common and app license keys, free licenses, expiration notices, and cloud environment activation |
| `trials-and-provisioning.md` | `PROVISIONING` | Trials, Console, Cloud, DXP, Liferay Data Platform, and AI Hub provisioning |
| `usage-and-utilization.md` | `USAGE` | Usage strategies, usage reports, and Liferay Data Platform metrics |
| `support.md` | `SUPPORT` | Tickets, ticket attachments, business events, and the JSM sync |
| `publisher-program.md` | `PUBLISHER` | Publisher sign up, the publisher dashboard, sales summaries, and payments |
| `sales-and-crm.md` | `SALES` | Salesforce opportunity sync and the Digital Sales Room |
| `administration.md` | `ADMIN` | The admin UI and back office tools |
| `notifications.md` | `NOTIFICATIONS` | Each email and in app notice, what sends it, and who gets it |
| `platform.md` | `PLATFORM` | Exports and downloads, product versions, the conventions for forms and lists, and browser storage |
